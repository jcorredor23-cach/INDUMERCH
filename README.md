# SteelFlow - InduControl (Industria 4.0)

Sistema avanzado de gestión y análisis predictivo para plantas de fundición y metalmecánica.

## Características Principales
- 🚀 **Dashboard en Tiempo Real:** Control total de órdenes de producción (COLADAS).
- 🧠 **Asistente IA:** Predicción de stock y análisis de impacto de incidentes usando Google Gemini.
- 📊 **Análisis Estadístico:** Diagramas de Pareto y métricas de rendimiento.
- 🛠️ **Gestión de Recursos:** Control de operarios, maquinaria y proveedores de mantenimiento.

## Instalación y Desarrollo
1. `npm install`
2. `npm run dev`
